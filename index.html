How it works›

Neural Canvas uses a Compositional Pattern Producing Network (CPPN) — a neural network that maps every pixel's coordinates (x, y, radius) plus a latent vector (α, β, γ) to an RGB color. The network has 9 hidden layers of 32 neurons each, producing smooth, organic, infinitely-detailed patterns.


Unlike traditional generative art using noise functions or pre-drawn assets, every pixel is computed by a unique neural network. Drag sliders to traverse latent space. Hit New Seed to randomize network weights. Enable Audio React to let your microphone drive the patterns — bass controls α, mids control β, treble controls γ.


Built with TensorFlow.js. No server, no API — runs entirely in your browser. Created for Hack the Arts 2026.
